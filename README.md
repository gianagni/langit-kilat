Langit Kilat (Lightning Sky) is a 2D canvas chase-view flight game over the Indonesian archipelago. You fly a little prop plane at sunset over islands, volcanoes and towns: steer through glowing rings for points and fuel, dodge storm clouds, radio towers and volcano peaks, and land on island runways to refuel and bank a 500 point bonus. Three lives, rising levels, a lit instrument HUD with altitude, speed and heading, and WebAudio synth engine hum, chimes and crash sounds. All art is drawn in code, all names are original, and the game runs offline from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Arrow keys steer and climb, W and S work the throttle, Space boosts, R restarts, P pauses, M mutes. The four screenshots in screenshots/ are real renders of the game's own deterministic ?shot= scenes.
